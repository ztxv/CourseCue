# Fonts used only to render `public/og-image.png`

These are not served by the website. They are loaded by `scripts/og-image.html`
so the link-preview card renders the same on any machine.

| File | Font | Why | License |
| --- | --- | --- | --- |
| `Caladea-Regular.ttf` | Caladea (Carolina Giovagnoli, Andres Torresi, Huerta Tipografia) | Open stand-in for Georgia, the serif the app uses for headings. Georgia cannot be redistributed. | SIL Open Font License 1.1 |
| `Geist-latin.woff2` | Geist (The Geist Project Authors, https://github.com/vercel/geist-font) | The app's sans-serif, the Latin subset exactly as `next/font` serves it. | SIL Open Font License 1.1 |

Both files carry their copyright and license in their font metadata. The full
license text is at https://openfontlicense.org/.
